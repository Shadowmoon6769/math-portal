1. Алгебра и уравнения
▼
Основная теорема алгебры:
Всякий многочлен степени n ≥ 1 имеет ровно n комплексных корней.
P_n(x) = a_n xⁿ + ... + a₀ = 0
Квадратное уравнение:
Формулы расчета дискриминанта и корней уравнения.
ax² + bx + c = 0
D = b² - 4ac
x₁,₂ = (-b ± √D) / (2a)
Теорема Виета:
Связь между корнями и коэффициентами квадратного уравнения.
x₁ + x₂ = -p
x₁ · x₂ = q

2. Тригонометрия
▼
Теорема синусов и косинусов:
Соотношения между сторонами и углами произвольного треугольника.
a / sin(A) = b / sin(B) = c / sin(C) = 2R
c² = a² + b² - 2ab · cos(C)

▼
Теорема Больцано-Коши:
О промежуточном значении непрерывной функции на отрезке.
